# Rekapin

*Bisnis Rapi, Data Terkendali.* Aplikasi Windows gratis untuk seller Shopee & TikTok Shop.

**Unduh:** halaman [Releases](https://github.com/judienmz/rekapin-releases/releases/latest) â†’ `Rekapin-Setup-x.y.z.exe`.

Repo ini hanya berisi file rilis yang dibaca aplikasi untuk update otomatis:
- `manifest.json` + `manifest.json.sig`: versi terbaru, ditandatangani Ed25519 dan dicek aplikasi sebelum dipakai.
- `templates/import_templates.json`: nama kolom & kamus biaya untuk import file marketplace.

Tidak ada data pengguna di sini. Rekapin tidak mengirim data apa pun ke repo ini; aplikasi hanya mengunduh.
